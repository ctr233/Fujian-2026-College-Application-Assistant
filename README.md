# 福建省2026志愿填报助手

一个纯前端、单文件的福建省高考志愿填报辅助工具。输入分数与选科，自动换算全省位次，并按“冲、稳、保”策略匹配院校专业组，帮助考生快速筛选志愿。

1.功能特点
- 分数位次换算：内置福建省2026年物理类一分一段表，输入分数即可换算全省位次。
- 冲稳保智能匹配：根据考生位次与院校专业组最低位次，按分段阈值判定“冲/稳/保”，并优先展示匹配度高的志愿。
- 多维筛选：支持按选科要求（化学、生物学、地理、思想政治）过滤院校专业组。
- 院校层次标签：自动标注 985 / 211 / 双一流 / 一本 / 二本 / 民办本科。
- 专业关键词高亮：
  - 红色：土木、环境、海洋、农业、医学相关
  - 绿色：信息、电子、电气、自动化、计算机、软件、人工智能、通信、网络、物联网相关
- 厦大提前排序：对 600 分以上考生，厦门大学相关专业组可优先展示。
- DeepSeek AI 志愿助手：内置聊天窗口，填入 API Key 即可对话咨询志愿问题。
- 本地运行：无需服务器，数据全部在本地浏览器中处理，不联网、不上传。

2.快速开始
将本仓库克隆到本地，或直接下载 `福建省2026志愿填报助手.html`，双击 HTML 文件，用浏览器打开即可使用。。

3.查询志愿
输入分数、选择选科要求，点击“查询”即可看到匹配结果。

4.数据格式说明
每一条院校数据对象包含以下字段：

字段	     类型	     说明
school	   字符串	   院校名称，如 "厦门大学"
group      字符串	   专业组，如 "500组"
minScore	 数字	     该专业组最低投档分
subject	   字符串	   选科要求，可选 "不限"、"化学"、"生物学"、"地理"、"思想政治"
tier	     字符串	   院校层次，可选 "985"、"211"、"双一流"、"一本"、"二本"、"民办本科"
majors	   字符串	   包含专业，多个专业用顿号分隔；可填 "详见招生简章"
提示：重复的院校+专业组+选科组合会被自动去重，无需手动清理。

5.AI 志愿助手（DeepSeek）
页面右上角有一个 DeepSeek 聊天窗口：

点击“获取 API Key”前往 DeepSeek 官网注册并创建 Key。

将 Key 粘贴到输入框中（仅保存在浏览器本地）。

即可与 AI 对话，咨询志愿填报策略、专业选择等问题。

注意：使用 AI 助手需要联网，并消耗你自己的 DeepSeek API 额度


6.技术实现
纯 HTML + CSS + JavaScript，单文件，无外部依赖。

数据预处理：去重 + 预算位次。

查询优化：位次区间粗筛 + 分页渲染（每页 60 条）+ DocumentFragment 批量插入。

高亮优化：正则预编译 + 缓存。

移动端适配：响应式布局。
